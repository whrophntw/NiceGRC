Model Context Protocol (MCP)

I am not a senior software engineer nor do I claim to be one, so I will spare you my crass explanation of how MCP functions and point you to the official documentation for your own research purposes.

They use the analogy that MCP is like a USB‑C port that standardizes the way electronics connect together. I liken it to an Application Programmable Interface (API). Regardless, the most important takeaway is that it is a standardized protocol written in TypeScript. This makes our lives easier in several ways:

  • We don't have to build a custom tool to connect to cloud infrastructure.
  • We don't have to stress about crafting a precise prompt and pray the agent doesn't go rogue… (assume it'll still go rogue)
  • We can use some of the most lightweight (re: low cost) models available because abstract reasoning is not required. Since the agent/LLM is taking action against logical (TypeScript/Python) code, there is no need to use the latest frontier magnaOpusCartaHolydivinity model to traverse the internetz and pull the cloud infrastructure data we want.
