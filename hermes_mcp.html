It took me more reading than I'd care to admit to grasp the difference between an API and MCP server. They both act as programmable gateways to a platform's internal data. However an API is communicating with an application with json. MCP is communicating with an LLM. The MCP server is formatted in a way to tell the model (similar to how a Skill file might instruct an LLM on how to perform a task) what it can access and how. The servers are usually written in python.
