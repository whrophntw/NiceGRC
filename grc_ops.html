The underlying principle

Both workflows rest on a three-layer stack:

  • Knowledge layer — the catalog of controls, applicability, and prior answers. The source of truth for what we do and why.
  • Evidence layer — the read-only Azure MCP server. The source of truth for what is actually deployed.
  • Orchestration layer — a Hermes skill that forces the agent to retrieve from the catalog before it ever cites the cloud.

Split these three apart and the agent stops being a confident liar. It can show its work.
