Nous Hermes Architecture > soul.md > config.yaml > Tools



In the root .hermes/ folder you will find: soul.md file, skills directory, config.yaml file


You will notice that there is not a directory for Tools. To find them you have to navigate to the .hermes/hermes-agent/ directory. This is your proverbial Barney Bag of gizmos, gadgets, odds and ends, and even some old strings... literally.




Finally, if you navigate to .hermes/hermes-agent/tools/ directory, you are presented with a sea of agent tools written in python code.



By now, someone new to agents but familiar with LLMs should start to understand that agents aren't LLMs with magical capabilities. Users use agents to prompt LLMs. The LLM reasons from memory. The agent uses the LLM to determine which tool (as python or other code) to use. The agent learns extensive/elaborate processes from skills. Agents access and retrieve external data from SaaS platforms with MCP.
